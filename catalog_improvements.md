# Melhorias do Catálogo - Toque Ideal

## Objetivos:
1. Criar um pré-catálogo com aviso de que está em construção
2. Informar que as imagens são meramente ilustrativas
3. Dividir peças por código
4. Incluir informação sobre personalização de cores no orçamento
5. Usar as imagens fornecidas pelo usuário

## Estrutura do Catálogo:
- Header com aviso de "Catálogo em Construção"
- Seção de produtos com códigos
- Cards de produtos com:
  - Código da peça
  - Imagem ilustrativa
  - Dimensões básicas
  - Botão "Adicionar ao Orçamento"
  - Aviso sobre personalização de cores

## Produtos de Exemplo:
- Usar as imagens fornecidas
- Criar códigos fictícios (TI-001, TI-002, etc.)
- Dimensões variadas
- Aviso sobre cores personalizáveis

## Avisos Importantes:
- "Catálogo em construção - Imagens meramente ilustrativas"
- "Cores e acabamentos podem ser personalizados no momento do orçamento"
- "Entre em contato para mais informações sobre disponibilidade"
